# Preethika Prasadi — Portfolio

A responsive, frontend-only portfolio built with Next.js App Router, TypeScript, Tailwind CSS v4, Framer Motion and Lucide React.

## Run locally

1. Install Node.js 20.9+.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Visit http://localhost:3000

## Before deployment

- Replace `public/preethika.jpg` if you have a newer professional portrait.
- Add your CV PDF to `public/Preethika_Prasadi_CV.pdf` and add a download link if you want a CV download button.
- Replace the generic LinkedIn profile links with your exact profile URL.
- Confirm the education dates shown as 2022–2026; update if needed.
- Add verified technology details for Guidely, Job Tracker and the older projects if you want their stacks shown more precisely.
- Check that all public project and certificate links are still accessible.

## Deploy

Push the project to GitHub and import it into Vercel. The default Next.js settings are sufficient.
